## Estimand and working measurement law

For each of the same600 cells, sum raw counts from all native retained genes
in the original selected bins intoS, and the complementary counts intoN-S.
Require exact conservation of total counts and original gene/cell identity.
The estimand is regional RNA log odds. Null logit ismu+sigma*z; alternative
logit ismu+delta*k+sigma*z, with fitted population prevalence and independent
standard-Gaussian statez. This is the existing conditional multinomial family
at two columns. Its binomial working law is not the exact conditional law of
heterogeneous gene-NB sums. Non-Gaussian transcription, composition and model
misspecification can still produce apparent discrete groups.

All numerical likelihood/fitting functions stay as previously executed. Only
the SVD initializer's structural rank bound changes: a centred two-column
matrix has one available contrast. This removes an unavailable second axis;
it does not add an initialization search. Same optimizer, starts,orders24/48/96
and native arithmetic remain. Existing feasible fits are shared across orders
until stable, with the original1000-sweep ceiling and failure propagation.

Use the same identity-hashed300/300 cell folds as the previous population
experiment. Fit and stop on training cells, predict target cells once in each
direction. The event itself was adaptively selected upstream using shared RNA;
this score is not independent genomic confirmation or a p-value. No reference
mean,simulator nuisance,state amplitude or clone labels enter fitting.
