## Method and what identifies the result

[Prespecified design](../dev/depth_conditioned_genes_20261109/DESIGN.md) and
[executed research implementation](../benchmarks/hardening/depth_conditioned_genes.py).

Estimand: relative regional RNA separation conditional on the original proposed
interval, responsibilities and nuisance fit. The working model is independent
integer gene NB observations. Use eight quantile strata of proposal counts
OUTSIDE the event. Retain strata containing both original hard q groups and
require at least30 actual contributing cells in each group. Each retained cell
has unit weight, making effective count equal actual count. No thinning or
fractional observation is used by the new comparison.

Within each contributing stratum, fit one common NB log-rate offset on proposal
event counts using the independently checked score root. A gene-specific
expected-count-weighted q fraction normalizes component multipliers so their
model-averaged stratum mean is unchanged at every candidate effect. The frozen
null and alternative share the fitted offset. Differences between strata alone
therefore do not supply the modeled CNA contrast. All original q, effect levels,
gene sizes, state priors, transition probability, boundaries and identity/order
remain. Exact state enumeration integrates one membership per cell across the
gene evidence. Gene likelihoods are summed into genomic bins before state runs.

Every stratum, offset, q fraction and cell selection is locked for ALL five
examples before opening any confirmation count arrays or full source CSR. The
input hashes also include full files for provenance. The model uses discovery
counts, not a hash as an inferential input. The new comparison is explicitly
called depth_conditioned, not depth_matched: a conditional model replaces the
balancing assumption. This does not prove matching was unnecessary.

The load-bearing assumption is that a common stratum abundance offset plus the
existing NB variance captures relevant depth nuisance. Within-stratum gene
programmes, reference misspecification and shared biological latent rates can
still create the distinction. Independent thinning does not itself remove that
biological dependence. Corresponding independent DNA establishes CNA validity
at its assay resolution. Complete-workflow null/power experiments establish the
claimed workflow error, not this conditional posterior. Biological n=0 here.
